TECHYFLEX FREE WEBSITE
======================

Files:
- index.html
- style.css
- script.js

Quick start:
1. Open index.html in Chrome to preview the website.
2. Replace placeholder # links in index.html with your YouTube/product links.
3. Replace your-email@example.com with your email.
4. Replace the Instagram link with your real Instagram profile.

FREE HOSTING:
Use GitHub Pages:
1. Create a GitHub account.
2. Create a public repository named YOURUSERNAME.github.io.
3. Upload index.html, style.css and script.js.
4. Open Settings > Pages and enable GitHub Pages.
5. Your free website will be at https://YOURUSERNAME.github.io/

No paid hosting is required.
